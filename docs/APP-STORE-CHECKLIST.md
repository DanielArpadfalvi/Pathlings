# App Store checklist (owner actions)

Everything that has to be done by hand in Apple's consoles. Tick in order.

## Account and app record
- [ ] Apple Developer Program membership active (individual or organisation).
- [ ] Certificates, Identifiers & Profiles → Identifiers: App ID **com.arpadfalvi.pathlings** with the *In-App Purchase* capability (Associated Domains only if Universal Links are added later).
- [ ] App Store Connect → My Apps → New App: name **Pathlings**, primary language English (U.S.), bundle ID above, SKU e.g. `pathlings-ios`.
- [ ] Add the Hungarian localization.

## In-app purchases
- [ ] Paid Apps agreement signed; banking and tax forms complete (IAPs cannot go live without them).
- [ ] Non-consumable **`pathlings_full_game`** – "Full game" / "Teljes játék", price tier **USD 2.99**; review screenshot of the offer sheet (`docs/store/screenshots/en/iphone-6.7/03-levels.jpg` shows the locks; take one of the offer sheet from the app or the web build with `?iap=mock`).
- [ ] Non-consumable **`pathlings_supporter`** – "Supporter pack" / "Támogatói csomag", **USD 2.99**, description: cosmetic only.
- [ ] **Family Sharing ON** for both purchases.
- [ ] Both purchases submitted together with the first app version.

## RevenueCat
- [ ] RevenueCat project with an Apple app (bundle ID above); App Store Connect in-app purchase key / shared secret uploaded as RevenueCat asks.
- [ ] Entitlements **`full_game`** and **`supporter`**, each attached to its product.
- [ ] Public Apple SDK key saved as the repository variable `REVENUECAT_IOS_KEY`.

## CI signing
- [ ] App Store Connect API key (role *App Manager*) → secrets `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8_BASE64`; team id → `APPLE_TEAM_ID` (see `docs/RELEASE.md`).
- [ ] Push a tag `v1.0.0`; check the build appears in TestFlight; test it on a device (purchase in the sandbox, restore, offline start).

## Store listing (per language, texts in `docs/store/listing.json`)
- [ ] Name, subtitle, promotional text, description, keywords (EN + HU).
- [ ] Screenshots: 6.7" (`iphone-6.7`), 6.5" (`iphone-6.5`), 12.9" iPad (`ipad-12.9`) from `docs/store/screenshots/<lang>/`.
- [ ] App icon is taken from the build (generated by `npm run assets`).
- [ ] Support URL: `https://github.com/DanielArpadfalvi/Pathlings/issues`; marketing URL optional.
- [ ] Privacy policy URL: the published `docs/site/privacy.html`.
- [ ] Category: Games → Puzzle (secondary: Strategy).
- [ ] Copyright: `2026 Dániel Árpádfalvi` (adjust to the legal name).

## App Privacy and rating
- [ ] App Privacy answers from `docs/store-privacy-answers.md` (decide the RevenueCat question first).
- [ ] Age rating questionnaire from the same file (expected 4+).
- [ ] Export compliance: "No" to non-exempt encryption (already set in Info.plist).

## Review
- [ ] Review notes: "Free download: World 1, World 2 levels 1–10, the daily level, the level editor and level codes are free. The non-consumable 'Full game' unlocks the rest; 'Supporter' is cosmetic. No account needed. Restore: Settings → Restore purchases."
- [ ] Never call the free part "Lite", "Demo" or "Trial" anywhere (guarded by tests).
- [ ] Submit; after approval release manually.
