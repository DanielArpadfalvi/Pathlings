## Findings

No **major** findings.

Minor, left as they are for 1.0:
1. Several levels can be won with exactly the required number (slack 0) – intended for the late levels, but a few W1 levels are strict for beginners; hints and the solution replay cover it. Revisit with real player data.
2. Skyreach's many permanent-skill assignments make ★★★ ("as few skills as the designer") demanding; the threshold equals the reference count, so it is always reachable.
3. In a crowd whose bodies overlap, a tap right on one Pathling may select its neighbour (ties are broken by walking direction); the loupe (hold 250 ms) is the precise way. The tutorial does not mention the loupe yet – worth a bubble in 1.1.

Fixed during this pass: the Play feature graphic is now generated (`docs/store/feature-graphic.png`); level W4-03 was titled "Cliff Climber" – a reference-game skill name – and is now "Cliff Hanger"; the release −/+ buttons had squeezed the pause button below 44 pt on 360 pt screens.
